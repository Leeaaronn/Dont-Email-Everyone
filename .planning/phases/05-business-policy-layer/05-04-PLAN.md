<objective>
Build the estimator the whole phase rests on: known-propensity IPW policy value on a
k-grid, with all three contrasts and a shared-draw bootstrap band.

Purpose: criterion 1 requires the policy's value to come from the randomization, not from
the model — D-02's point being that summing predicted uplift makes the headline a
restatement of the model's own belief about itself. `05-RESEARCH.md` measured the
consequence of getting that wrong: at the anchor, the spend model believes it is delivering
exactly twice what the randomization says it delivered.

Criterion 1's literal "(1/3)" is the DESIGN propensity. The frame this estimator actually
runs on is the 21,347 womens+control rows, because `uplift_womens_*` is NaN on every mens
holdout row. Conditioning on `A in {womens, control}` — a function of a randomly assigned
variable, so no selection bias — gives `P(A = womens | A in {w,c}) = 1/2` and a
Horvitz-Thompson weight of 2. Transcribing 3 instead inflates "email everyone" to
$1.7227/customer against an actual womens-arm mean of $1.1462. ROADMAP criterion 1 was
amended in place to say so (D-16).

Output: `POLICY_WEIGHT`, `policy_value_curve` and `policy_value_band` in `evaluation.py`.
</objective>

Implementation, in one pass over cumulative sums:

    t, y = _ranked_arrays(score, treatment, outcome, seed)   # the project's ONE sort
    cum_t = concat([[0.0]], cumsum(where(t == 1, y, 0.0)))
    cum_c = concat([[0.0]], cumsum(where(t == 0, y, 0.0)))
    m      = (n * grid).astype(int)                          # TRUNCATION
    v_pi   = weight * (cum_t[m] + (cum_c[-1] - cum_c[m])) / n
    v_all  = weight * cum_t[-1] / n
    v_none = weight * cum_c[-1] / n
    delta_none   = v_pi - v_none
    delta_all    = v_pi - v_all
    delta_random = delta_none - grid * (v_all - v_none)

published total, and `delta_none / k` does not have that property. Record BOTH numbers in
the docstring so the discrepancy reads as resolved rather than unnoticed.

Add a docstring paragraph on the two identities that make criterion 4 free and D-08a
