<objective>
Make the phase runnable and make a default deployment honest.

Purpose: `streamlit` is not installed in `.venv` (verified 2026-09-10), so nothing else in this
phase can be written or executed. And `browser.gatherUsageStats` defaults to `True` in
streamlit 1.63.0, so a repo deployed without `.streamlit/config.toml` phones home on every
session — which ROADMAP criterion 4 forbids. Both are gates, not polish, which is why they are
Wave 0 and why every other plan in the phase depends on this one.

Purpose (second half): Community Cloud searches the entrypoint's own directory and then the repo
root for a dependency file and installs **only the first one it finds**. With a single root
`requirements.txt` that is already the slim set, there is no fat file for it to find. The failure
mode of getting this wrong is silent — the app runs perfectly while carrying scikit-learn,
statsmodels, DuckDB and Pandera at serve time.

Output: streamlit installed, three layered requirements files with one pin per package,
`.streamlit/config.toml` committed, the README's streamlit-absence note corrected, and
`tests/test_app.py` opened with the two file-parse tests that guard all of it.
</objective>
