<objective>
Give the committed policy-curve factory a moving marker, and prove the committed figures did not
move.

Purpose: ROADMAP criterion 2 requires the curve to mark **the selected point** alongside the
"email everyone" reference and the confidence band. The committed PNGs cannot serve that — they are
static and the selection moves. D-04 forbids a second chart implementation in the app layer,
because the hatched covers-zero encoding the 05-08 legibility checkpoint approved would end up
rendered two slightly different ways. So the marker goes into `plots.py`, as one keyword-only
parameter defaulting to `None` that draws nothing when `None`.

This is the second half of D-06's proof. Plan 06-02 proved the relocation is behaviour-free at the
code level. This plan regenerates every committed artifact and figure with **both** changes in place
and requires git to report no change at all.

Output: `selected=` on `policy_curve_plot`, one new figure colour constant, two new tests, and a
recorded clean `git status` after a full regeneration.
</objective>
