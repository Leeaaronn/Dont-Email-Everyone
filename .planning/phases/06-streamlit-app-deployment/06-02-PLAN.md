<objective>
Break `plots.py`'s statsmodels dependency without changing a single drawn pixel.

Purpose: the app must reuse the committed figure factories (D-04), but `plots.py` does
`from dont_email_everyone import ate, balance` at module level, and those two modules import
statsmodels and scipy. Measured: `import dont_email_everyone.plots` today leaves **2,029 modules**
in `sys.modules`, including 373 statsmodels submodules, 23 patsy and 540 scipy. ROADMAP criterion 4
requires the serve-time set to exclude statsmodels, so as it stands the app cannot import the
module it is required to reuse.

The entire dependency is **two names**: `ate.OUTCOMES` at `plots.py:1749` and
`balance.SMD_THRESHOLD` as `love_plot`'s default argument at `plots.py:150`. Nothing else in the
file touches either module. Moving both into `config.py` — which imports only `pathlib` and `types`
and is already imported nearly everywhere — drops the closure to **433 modules** with statsmodels,
scipy, patsy, sklearn, duckdb and pandera all absent.

This edits modules Phases 2 and 4 closed, which is exactly why D-06 demands the change be proven
behaviour-free rather than assumed. This plan proves it at the *code* level (identity, immutability,
every call site green, import closure measured). Plan 06-03 proves it at the *artifact* level, by
regenerating everything and requiring `git status` to come back empty.

Output: two constants relocated, two re-export shims, one import line replaced, and four test files
extended.
</objective>
