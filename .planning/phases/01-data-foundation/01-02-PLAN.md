Create `dont_email_everyone/ingest.py` with the checksum gate. Import order: `hashlib` and `pathlib` from stdlib, blank line, third-party (none yet in this task), blank line, `from dont_email_everyone import config`. Define:
  - `class ChecksumMismatchError(RuntimeError)` with a docstring — a project-defined exception, not a bare `RuntimeError` or an `assert`, so callers can catch precisely and so the failure is self-describing in a traceback.
  - `sha256_file(path, chunk_size=1 << 20) -> str` — streams the file in 1 MiB chunks via `iter(lambda: fh.read(chunk_size), b"")` against a `hashlib.sha256()` digest, opened in binary mode. Constant memory; do not read the whole 4 MB file into a bytes object.
  - `read_expected(checksum_path) -> str` — reads the sidecar, takes the first line, splits on whitespace, returns the first field lowercased. This is the `sha256sum` format: `<64 hex>  <filename>`, two spaces.
  - `verify_checksum(csv_path, checksum_path) -> str` — computes the actual digest (letting `FileNotFoundError` propagate unwrapped if the file is absent), compares to the expected, and on mismatch raises `ChecksumMismatchError` with a message containing the path, the expected digest, and the actual digest. On success it returns the digest.

Three properties that must not drift: (a) `verify_checksum` raises — it never returns a boolean the caller may ignore and never warns-and-continues; (b) `FileNotFoundError` propagates rather than being caught and re-wrapped, so a missing file is distinguishable from a corrupted one; (c) there is no `except: download()` branch, no fallback fetch, and no network import anywhere — CLAUDE.md's provenance constraint and ROADMAP criterion 1 forbid it, and `tests/test_no_network.py` from Task 1 enforces it.

The `newline=""` argument is load-bearing: without it Windows translates the trailing `\n` to `\r\n` and the sidecar stops being consumable by `sha256sum -c`. Note two spaces between digest and filename — that is the `sha256sum` format, and matching it gives an independent cross-check on your own hashing code using standard OS tooling.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-05 | Tampering | `data/raw/hillstrom.csv` modified after vendoring | mitigate | `verify_checksum()` raises `ChecksumMismatchError` on every run rather than warning; proven by `test_tampered_file_raises`, which appends a plausible-looking row that a row-count or schema check would miss. |
| T-01-06 | Tampering | integrity check defeated by toolchain line-ending normalization | mitigate | `test_git_blob_matches_checksum` hashes `git cat-file` output in binary mode, plus `test_committed_blob_size` (3,964,977 not 3,900,976) and `test_linux_style_clone_preserves_bytes`. This verifies the artifact a cloner receives, not the local working tree. |
| T-01-07 | Spoofing | pipeline silently substituting a re-downloaded file for the vendored one | mitigate | `tests/test_no_network.py` greps the whole `dont_email_everyone` package for `requests`/`urllib`/`httpx`/`aiohttp`/`urlretrieve`/`socket`/`ftplib`/`http.client` and fails if any appears. No `except: download()` branch may exist; `verify_checksum` has no fallback path. |
| T-01-08 | Repudiation | no record of which file version produced a result | mitigate | `data/raw/CHECKSUMS.sha256` in `sha256sum` format is committed next to the data, cross-checkable with standard OS tooling independent of this project's code. |
| T-01-09 | Elevation of Privilege | post-treatment outcome columns leaking into the feature set in Phase 4 | mitigate | `PRE_TREATMENT_FEATURES` is a hard-coded literal constant in `config.py`, never a computed drop; `test_no_post_treatment_leakage` asserts `visit`/`conversion`/`spend`/`segment` are absent. (Not a security threat per se, but it is the integrity threat this phase's ROADMAP criterion 5 exists to block, so it is registered here.) |
| T-01-10 | Tampering | subprocess argument injection in the provenance tests | accept | All `git` invocations use fixed argument lists with `shell=False` (subprocess default) and internal constants only; no user input reaches them. |
